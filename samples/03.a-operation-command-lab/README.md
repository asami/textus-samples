# 03.a-operation-command-lab

## Overview

This lab covers the first command-oriented operation contract line.

It follows [03-operation](/Users/asami/src/dev2026/cncf-samples/samples/03-operation), which fixes the minimal query-oriented contract line first.

## Scope

This lab focuses on:

- command-shaped `TYPE`
- `INPUT/OUTPUT > VALUE`
- `SUMMARY`
- `DESCRIPTION`

The runnable first line is:

- `SERVICE > OPERATION`
- `TYPE = COMMAND`
- `INPUT > VALUE`
- `OUTPUT > VALUE`
- `command help operation-command-contract-sample.greeting.submit-greeting`

Verified help return:

- `GreetingAccepted`

Entity-integrated command behavior belongs to a later lab.
