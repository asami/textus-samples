# 01-minimal

## Overview

This is the smallest executable CNCF sample.
It covers the minimum structure of 1 Component, 1 Service, and 1 Operation.

## Structure

- Component
- Service: `main`
- Operation: `hello`

## How To Run

After implementation, run it in the following form.

```bash
sbt run command minimal.main.hello
```

## Example Commands

```bash
sbt run command minimal.main.hello
```

## Key Learnings

- The smallest unit of Component / Service / Operation
- The basic shape of an executable sample
