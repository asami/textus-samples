# 01.d-component-script

## Overview

This sample explains how to build small management commands by wrapping a Component command path with a thin shell script.

## Structure

- Script-oriented learning sample
- Focused on Component command invocation
- Companion to `01-minimal`

## How To Run

This sample is documentation-first for now.
The concrete script flow will be added after the examples are fixed.

## Example Commands

```bash
cd ../01-minimal
./run.sh
./invoke.sh
```

## Key Learnings

- management commands can be modeled as Component operations
- shell scripts should stay thin
- command paths can act as operational contracts
