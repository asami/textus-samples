# Phase

This directory manages the work plan and progress checklists for `cncf-samples`.

- A Phase represents a broad work objective
- A Subphase represents a focused area within that Phase
- A Checklist is the only authoritative basis for progress

Operational semantics follow `ai/directive/core/phase-subphase-checklist.md`.

Current primary documents:

- `foundation-plan.md`
  - Overall plan from repository foundation through sample implementation
  - Phase-level status and cross-sample exit criteria
- `samples/`
  - Per-sample progress tracking documents
  - Independent checklist management for each sample
