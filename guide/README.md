# Guide

This directory stores user-facing documentation.

It is intended for people who want to:

- understand how to run a sample
- understand how to invoke a component or subsystem
- understand the calling contract after deployment or packaging
- understand how to build small script-style management commands from Component operations

By contrast, `docs/` is reserved for sample development documentation:

- planning
- design notes for implementers
- rules
- specifications
- engineering journal records
